# 軌道保存を満たすシースモデル

この文書は Issue #1–#7 に対するモデル修正を定義します。v0.1.0 の局所 shifted Maxwell 分布を
使った式とは数値結果・解の存在域が変わります。Zhao の粒子集団と A/B/C の構造を用いますが、
論文の閉形式をそのまま再現する実装ではありません。

## 背景電子の定義

温度を eV、上流電位を 0 とし、`v_th=sqrt(2 e T_e/m_e)`、`u=v_d/v_th`、
`psi=phi/T_e` とします。上流で内向きに進む粒子の速度の大きさ `a=v_infinity/v_th >= 0` に対し、
分布を `g(a)=N_e exp(-(a-u)^2)/(sqrt(pi) v_th)` と定義します。
電子のエネルギー保存から局所速度の大きさ `w=abs(v_z)/v_th` は

```text
w^2 = a^2 + psi
g_local(v_z) = N_e/(sqrt(pi) v_th) * exp(-(sqrt(w^2-psi)-u)^2)
```

です。`w^2 < psi` の速度には上流につながる軌道がないため分布を 0 とします。
ドリフトが非ゼロのとき、`exp(psi)*exp(-(w-u)^2)` への分離はできません。

`b=sqrt(-phi_min/T_e)` とすると、表面まで到達する粒子は `a>=b`、局所では
`w>=sqrt(psi+b^2)` です。A の上側と C では、到達できない低エネルギー集団が内外の両方向に存在します。
A の下側と B に背景電子の反射集団はありません。

密度はこの局所分布の速度積分です。Fortran と Python は速度端点を二乗変換した複合 Gauss 積分を用います。
流束は同じ積分で `w dw = a da` と変数変換することで

```text
Gamma_e,passing = N_e v_th/(2 sqrt(pi)) *
                 [exp(-(b-u)^2) + sqrt(pi) u erfc(b-u)]
```

となり、通過粒子の流束は位置に依存しません。Python の VDF は上記の軌道分布を返し、
`fluxes_at_z` は表示格子の台形積分ではなく、この分布の流束積分を評価します。

B は `phi_min=0` であり、速度下限は `sqrt(2 e phi/m_e)` です。
特に `u=0` では `n_e/N_e=exp(psi)*erfc(sqrt(psi))/2` になります。
A の `phi_min -> 0-` の下側極限も同じ密度・流束になります。

## 半無限プロファイルの存在条件

準中性や零電流の代数方程式を満たすだけでは物理解としません。冷たいイオンの到達条件と、
電位経路に沿った Poisson 一次積分の非負性を調べます。

```text
A lower/upper: E^2(phi) = -2/eps0 * integral(phi_min..phi, rho dphi)
B/C:           E^2(phi) =  2/eps0 * integral(phi..0, rho dphi)
```

A は上側積分の遠方端でも `E=0` が必要です。J=0 と E_H 指定は共通の判定処理を使います。
積分は密度評価と同じ分布に基づく数値積分なので、旧式の `(exp(2*u*s)-1)/u` は不要です。
`u=0` とその近傍にも除算の特異点はありません。

さらに、**内向きドリフト `u>0` の背景電子と完全反射を仮定した A/C は、厳密な半無限上流条件に接続できません**。
上流の低速部分では `g'(0)>0` であり、`h=-psi -> 0+` に対する密度差に

```text
n_e(-h)-n_e(0) = N_e u exp(-u^2)/sqrt(pi) * h log(1/h) + O(h)
```

が現れます。イオンと光電子の正則な項よりこの項が支配的になり、上流近傍の `E^2` が負になります。
有限の電位サンプルでは見逃す場合があるため、ドリフトの符号と反射集団の有無からも判定します。
例えば太陽高度60度の旧既定条件を軌道写像へ修正した A 代数根は、上流近傍で負の一次積分を持ちます。
高度20度の負の表面電位を持つ代数根も、さらに上流へ近づくと同じ問題を持ちます。

この制約を隠すためにドリフトを自動で変更しません。J=0 では `electron_drift_mode='zero'`、
E_H 指定では `electron_drift_mps=0` とすることで、無ドリフトの別の物理条件を明示できます。
有限高さの上流境界、衝突、異なる低速 VDF を導入する場合は別の境界モデルが必要です。

経路検査は有限個の点での数値判定であり、任意のパラメータに対する存在定理ではありません。
代数根が物理条件を満たさない場合は `sheath_no_physical_solution`、数値探索・積分の失敗は
`sheath_numerical_failure` を返します。

## 枝のトポロジーとゼロ電場

- A: `phi_min < min(phi_H,0)`。表面電位が負でも探索します。境界から極小までは `E_H>0`。
- B: `phi_H>0` から上流の 0 へ単調に減少し、`E_H>=0`。
- C: `phi_H<0` から上流の 0 へ単調に増加し、`E_H<=0`。

`E_H=0` は平坦状態だけを意味しません。通常の非平坦な B/C 根も探索し、
正の規格化密度を持つ平坦状態は候補の一つとして追加します。
A の極小が境界へ移動する遷移点は C のゼロ電場端点として表現できます。
API は状態を保持せず、近傍の電場を順に指定して候補を比較できます。

## 固定量と未知量

`solve_prescribed_field` は **neutrality-adjusted closure** です。

| 呼び出し側が固定 | ソルバーが決定 |
| --- | --- |
| E_H、上流イオン密度・速度、電子温度・ドリフト、粒子質量、光電子源密度・温度 | 境界電位、A の内部極小電位、背景 Maxwell 分布の規格化 N_e、応答電流 |

`ambient_electron_density_m3` は `N_e` です。実際の上流背景電子密度は、入射・反射の速度域を
積分した値であり、`N_e` 自体ではありません。さらに光電子の上流到達集団も準中性に寄与します。
E_H を変えると、準中性と接続条件を満たすために N_e も変わります。

背景電子の規格化まで固定する `fixed_ambient` を、同じ入力へ単に追加することはしません。
現行の半無限条件を保持したまま N_e と E_H を独立に固定すると一般に過剰決定となります。
N_e を固定して E_H を出力するか、有限境界・源の自由度を加えるなど、何を解放するかの指定が必要です。

このモデルは BEACH から出てくる任意の電子・イオン VDF を受け取る kinetic boundary operator ではありません。
BEACH の outward flux 計測値は背景 VDF の更新に使用せず、光電子は Maxwell 源の密度・温度へ集約します。

## 複数解の選択

`require_unique` が既定です。有限個の初期値から発見した候補が複数なら曖昧性を返します。
`solve_prescribed_field_candidates` は選択せず候補を返し、それぞれの電位・密度・流束・電場エネルギーを比較できます。
有限の探索で全ての根を列挙できる保証はありません。

`field_energy_j_m2 = +(eps0/2) integral(E^2 dz)` は正の静電場エネルギーです。
`max_field_energy` はこれが最大の候補を選ぶ **ヒューリスティック** です。
粒子のエネルギーや境界源の仕事を含まないため、安定解・実現する枝・熱力学的最小値を意味しません。

動的安定性や履歴に依存する枝選択は、本 API では判定しません。
