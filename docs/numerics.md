# 数値解法と検証

このページでは、[物理モデル](model.md) の方程式をどのように無次元化・数値評価・求解しているか、およびテストスイートと検証記録の内容をまとめます。

- 各設定項目の引数名と既定値 → [Fortran API（`sheath_solver`）](fortran-api.md#sheath_solver) / [Python API（`SheathSolver`）](python-api.md#sheathsolver)

---

<a id="規格化"></a>

## 1. 内部の規格化

ソルバー内部では、電位を電位尺度 $V_s$、密度を密度尺度 $n_s$、長さを Debye 長型の尺度 $\lambda_s = \sqrt{\varepsilon_0 V_s / (e n_s)}$ で無次元化して解きます。

| 入力の種類 | 電位尺度 $V_s$ | 密度尺度 $n_s$ |
| --- | --- | --- |
| 固定入口・$E_H$ 指定・静的評価（Maxwell 源） | 放出電子温度 $T_{\mathrm{em}}$ | 上流イオン密度 $n_{i\infty}$ |
| 同上（bin 源、Fortran） | $T_e$ 以下で最大の $2$ の冪 [V] | 上流イオン密度 $n_{i\infty}$ |
| 太陽高度入力（`zhao_equilibrium_input` / `ZhaoParams`） | 光電子温度 $T_{\mathrm{pe}}$ | 参照光電子密度 $n_{\mathrm{pe,ref}}$ |

> [!NOTE]
> **なぜ bin 源の電位尺度に 2 の冪を使うのか**  
> IEEE 754 binary64 では $2^k$ による乗除算で仮数部が一切丸められません。これにより、物理単位 [V] と内部無次元単位を往復しても bin 端が 1 ulp もずれず、区分一定のスペクトル境界を厳密に保持できます（放出源の有効温度を推定しているわけではありません）。

`residual_tolerance` や `potential_extent` は、この無次元規格化のもとでの値です。

## 2. 密度・流束・電場積分の評価

- **背景電子**
  - ドリフトが厳密に $0$ のときは全 Type で解析式を用い、$e^\psi \mathrm{erfc}(\cdot)$ のオーバーフローを防ぐため `erfc_scaled`（Python は `scipy.special.erfcx`）で評価します。
  - ドリフトがある場合は、下限速度の平方根特異性を除く変数変換 $w = w_{\mathrm{lo}} + (w_{\mathrm{hi}} - w_{\mathrm{lo}}) t^2$ を施した複合 Gauss 求積で局所分布を積分します。速度の裾はドリフトまたは下限から熱速度の $10$ 倍で打ち切ります。
  - 通過電子の数流束は等価な上流側積分（$w\,dw = a\,da$）で評価し、位置に依存しない厳密な保存を保ちます。
- **放出電子**
  - Maxwell 源・bin 源ともに解析式を用います。
  - bin 源では、平方根の差の有理化と、$3/2$ 乗の差に対する bin 幅・電位区間幅の因数分解を行い、狭い bin や隣接する浮動小数点端点で桁落ちが起きないようにしています。
- **Poisson 一次積分（$E^2$ 評価）**
  - 電荷密度を電位で積分します。bin 源の放出電子寄与は $3/2$ 乗差の解析積分、イオンと背景電子の寄与は 4 区間 $\times$ 16 点（計 64 点）の複合 Gauss 求積で評価します。
  - 密度と同じ分布関数から直接積分するため、$u = 0$ とその近傍でも除算の特異点はありません。
  - Fortran を OpenMP 有効でビルドした場合、64 点の密度評価を並列実行します。総和は固定順序で取るため、計算結果はスレッド数に依存しません。
- **Type A の接続残差**
  - 上流側の一次積分を $(-\hat{\phi}_m)^{3/2}$ で規格化し、浅い極小で積分区間が縮むだけで残差が小さく見える現象を防ぎます。
  - 無ドリフトの浅い Type A では、上流中性状態からの密度差と平方根差を因数分解して積分し、密度同士の引き算による桁落ちを回避します。SI 単位の `connection_residual_v2_m2` はこの規格化残差から復元します。

<a id="根の探索"></a>

## 3. 根の方程式と探索アルゴリズム

### 未知数と座標変換

| 閉じ方 | Type A の未知数 | Type B / C の未知数 | 解く連立方程式 |
| --- | --- | --- | --- |
| $J_z = 0$ | $\phi_H,\ \phi_m,\ N_e$ | $\phi_H,\ N_e$ | 上流準中性、$J_z = 0$、A は上流接続 |
| $E_H$ 指定 | 同上 | 同上 | 上流準中性、境界 $E^2 = E_H^2$、A は上流接続 |

探索中は、正のギャップ $\phi_H - \phi_m$ や負の極小 $-\phi_m$、正の規格化密度 $N_e$ を対数座標へ変換し、定義域外を評価しないように保護しています。静的評価は非線形探索を行わず、与えられた電位で上流準中性から $N_e$ を直接計算します。

### 探索手法（`search%method` / `SearchOptions.method`）

| `method` | 動作 |
| --- | --- |
| `auto`（既定） | 定義域検査と backtracking 付きの Newton 法を実行し、前進できない場合は Levenberg–Marquardt（LM）へ切り替える |
| `newton` / `lm` | 同じ定義域保護付きで、それぞれ Newton 法 / LM 法のみを実行する |
| `bracket` | Type B または C を明示したときのみ利用可能なスカラー探索。$J_z = 0$ は零電流式、$E_H$ 指定は準中性式で $N_e$ を消去し、1 変数関数の符号変化を括弧付けする |

- **収束判定**：必ず元の規格化方程式の最大絶対残差が `residual_tolerance` 以下になったときのみ収束とみなします。ステップ幅の縮小や最小二乗の停留点は収束とみなしません。
- **初期値**：温度・密度比に応じた無次元の標準初期値（`use_default_guesses`）、呼び出し側が渡した `initial_guesses`、および解マップからの予測を使います。
- **$E_H$ 指定の Type B / C（`auto`）**：スカラー探索と多点出発の Newton / LM を併用します。スカラー探索の格子には、bin 端とその直前・直後の浮動小数点値、対数・線形の電位点を含め、曲率に応じて最大 `scalar_max_depth` 段まで区間を細分化します。極値探索により近接根の組や接する根も探します。無効な評価点をまたいで区間を結ばず、区間幅下限到達や正残差の極小は収束とみなしません。
- **複数候補の列挙（`deflation`）**：shifted deflation で既知の根を退けて別解を探します。発見した候補は必ず元の方程式と物理解判定で再検証し、重複を除外します。
- **採用と失敗ステータス**：収束した根のうち [物理解の判定](model.md#物理解の判定) を通ったものだけを返します。`auto` では不適格な根を飛ばして次の Type を試します。採用解がなく、棄却と未収束が混在した場合は `SHEATH_NUMERICAL_FAILURE` を返します。

## 4. 解マップ（Atlas）と continuation

解マップは、受理済みの物理解を **無次元パラメータキー** と無次元解座標で保存する表です。

| 解マップの種類 | 無次元キー（特徴ベクトル） |
| --- | --- |
| $J_z = 0$（6 次元） | $\ln(T_e/V_s),\ \operatorname{asinh}(u),\ \ln(u_{i\infty}/v_s),\ \ln(m_i/m_e),\ \ln(1 + \alpha/V_s),\ \ln(1 + \text{規格化放出流束})$ |
| $E_H$ 指定（7 次元） | 上の 6 次元に $\operatorname{asinh}(E_H / E_s)$ を追加 |

ここで $v_s = \sqrt{2eV_s/m_e}$、$\alpha = (\text{\texttt{ion\_pressure\_factor}})\cdot T_i$、$E_s = V_s / \lambda_s$ です。Type（A/B/C）、`component`、bin スペクトルの規格化形状はキーとは別に区別し、異なるスペクトル形状の記録は問い合わせに混ぜません。

**問い合わせ時の動作**（常に元の方程式を解き直します）：

1. 近傍記録から局所線形予測（リッジ正則化付き、`interpolate = .true.`）を作り、近傍の根とともに初期値として元の方程式を解く。
2. それでも解けない場合、近傍記録から問い合わせ点へ無次元経路パラメータ $t: 0 \to 1$ に沿って **continuation** を実行する。
   - `parameter`：予測子–修正子法で $t$ を適応刻みで進める。
   - `arclength`：擬似弧長の接線条件を加え、単純な折り返し（fold）を越えて追跡する。
3. 経路上の各点はすべて物理解判定を通過する必要があり、1 刻みの解移動が `max_root_distance` を超えた場合は刻みを縮めて再試行します。最終点は必ず問い合わせ条件そのもので解き直します。
4. 表の構築（`build_*_atlas`）では、後から見つかった近傍解を用いて未解決点を再探索します。空白領域は解の不存在を意味しません。

## 5. プロファイルの再構成

### Zhao モデル

既存の $J_z = 0$ 根から、半無限の Poisson 一次積分を用いて $dz = d\phi / \lvert E(\phi) \rvert$ を積分します。

- **Type A**：極小 $\phi_m$ を起点に境界側と上流側の 2 区間を構成し、極小近傍の $1/\sqrt{\phi - \phi_m}$ 型特異性は解析的に処理します。
- **Type B / C**：上流の厳密な電位から積分し、無限遠端点を除きます。
- 電位格子は端点近くに密に配置し、上流側は打ち切り電位または上限高さ（受理した上流の帯がある場合は帯の手前）で停止します。人工的な $0\text{ V}$ の延長区間は付け足しません。

### 固定入射モデル（Python）

- **有限箱（`solve_finite_column`）**：Poisson 一次積分から得られる長さを箱高 $H$ に一致させます。単調解で内部に低電場領域がある場合は $\operatorname{asinh}$ 座標で分解し、谷を持つ解は深さ走査で箱高を括弧付けします。
- **外側領域付き（`solve_presheath`）**：候補電位ごとに電子軌道を積分して準中性電位を求めます。`B_out` では谷の壁側の光学距離 $\tau(\phi)$ を三次スプラインで表し、各節点の準中性・接合点の折り返し条件・壁の零電流を連立求解します。電位が $0\text{ V}$ を横断する場合は、軌道積分とスプライン区間を $0\text{ V}$ で分割します。

## 6. 浮動小数点の端点（`electron_normalization_m3`）

急峻なスペクトル応答などでは、利用側の外側方程式を満たす電位が隣り合う binary64 表現可能値の間に落ち、どの浮動小数点電位でも残差許容値を満たせない場合があります。

Fortran の静的評価 [`evaluate_sheath_state`](fortran-api.md#静的評価) の省略可能引数 `electron_normalization_m3` は、Type B / C で現在電位の直前・直後の binary64 電位から求めた中性密度 $N_e$ の間に限って $N_e$ を指定できるようにします。密度・積分・流束はすべて指定した同一の $N_e$ で再計算し、準中性残差と物理解判定の許容値は一切緩めません。外側方程式の構成・括弧付け・時間積分は利用側の責務です。

## 7. 検証とコンパイラ確認記録

自動テストスイートは `fpm test`（`test/`）および `python -m unittest discover -s tests -v`（`tests/`）で実行でき、以下の項目を検証しています。

- **分布・モーメント・保存則**：速度モーメントと独立な適応積分・Simpson 積分の比較、無ドリフト Type B 解析式および Type A $\to$ B 極限の一致、通過流束の位置不変性、$\Gamma_{\mathrm{escape}} + \Gamma_{\mathrm{return}} = \Gamma_{\mathrm{out}}$。
- **物理判定とプロファイル**：不適格な代数根の棄却、負の表面電位を持つ Type A プロファイル、非平坦な $E_H = 0$ 遷移、プロファイル上の $E = -d\phi/dz$ と $dE/dz = \rho/\varepsilon_0$ の整合。
- **bin 放出源と端点精度**：独立な局所速度積分・電位積分との一致、Maxwell 源細分化との一致、同一モーメントで形状の異なる分布の識別、bin 端の片側極限、狭い bin・隣接電位での桁落ち耐性、BEACH batch-154 スペクトルと独立高精度静的参照値の比較。
- **拡張機能と結合 API**：上流の帯の受理、温かいイオン流体、解マップと continuation、matching plane 条件とプロファイル極値・電場の一致、外部解の更新・失敗時の前状態保持・stream/sequential 再開・版不一致検出、電場と電流の候補選択。
- **固定入射モデル（Python）**：分岐境界の判定、有限箱での谷の位置、外側領域モデルの 4 枝（`A`, `B_out`, `B_nw`, `C`）と $0\text{ V}$ 横断、壁電流と外側領域の準中性残差。
