# 数値解法と検証

[物理モデル](model.md) の方程式をどう数値的に解き、どう検証しているかをまとめます。
API の設定項目は [Fortran API](fortran-api.md#sheath_solver) と [Python API](python-api.md#sheathsolver) を参照してください。

## 規格化

内部では電位を電位尺度 V_s、密度を密度尺度、長さを $\sqrt{\varepsilon_0 V_s/(e\,n)}$ で規格化します。

| 入力 | 電位尺度 V_s | 密度尺度 |
| --- | --- | --- |
| 固定入口・E_H 指定・静的評価（Maxwell 源） | 放出電子温度 T_em | 上流イオン密度 |
| 同（bin 源） | T_e 以下で最大の 2 の冪 [V] | 上流イオン密度 |
| 太陽高度入力 | 光電子温度 | n_pe,ref |

bin 源の尺度を 2 の冪にするのは、規格化の往復で bin 端が 1 ulp ずれないようにするためで、推定した源の温度ではありません。
`residual_tolerance` と `potential_extent` はこの規格化での値です。

## 密度・流束・電場の評価

- **背景電子**: ドリフトが厳密に 0 なら全 Type で解析式を使い、$e^{\psi}\mathrm{erfc}(\cdot)$ を `erfc_scaled`（Python は `erfcx`）で評価します。
  ドリフトがあれば、速度の端点を $w=w_{lo}+(w_{hi}-w_{lo})t^2$ で変換した複合 Gauss 積分で局所分布を積分します。
  速度の裾はドリフトまたは下限から熱速度の 10 倍で打ち切ります。
  通過電子の流束は等価な上流側の積分（$w\,dw=a\,da$）で評価し、位置によりません。
- **放出電子**: Maxwell 源は解析式、bin 源は bin ごとの解析式です。平方根の差は有理化し、3/2 乗の差は bin 幅と電位区間の両方を因数分解して、
  狭い bin や隣接する浮動小数点の端点で近い値どうしを引かないようにしています。
- **Poisson 一次積分**: 電荷密度を電位で積分します。bin 源の放出電子の寄与は 3/2 乗の差の解析式、
  イオンと背景電子の寄与は電位の数値積分です。密度と同じ分布を使うので、u=0 とその近傍にも除算の特異点はありません。
- **A の接続残差**: 上流側の積分を $(-\hat\phi_m)^{3/2}$ で割ります。極小が浅いだけで積分区間が縮み、残差が小さく見えることを防ぎます。
  ドリフトのない浅い A では、上流の中性状態からの密度差と平方根差を因数分解して積分し、密度どうしの桁落ちを避けます。
  SI の接続残差はこの規格化残差から戻します。

## 根の方程式と未知数

| 閉じ方 | A の未知数 | B/C の未知数 | 方程式 |
| --- | --- | --- | --- |
| J=0 | φ_H、φ_m、N_e | φ_H、N_e | 準中性、零電流、A は接続 |
| E_H 指定 | 同上 | 同上 | 準中性、境界の E² = E_H²、A は接続 |

未知数は正のギャップ φ_H − φ_m、負の極小などの対数座標に変換し、定義域の外を評価しないようにしています。
静的評価は未知数を解かず、与えた電位での準中性から N_e を直接求めます。

## 根の探索

| `method` | 動作 |
| --- | --- |
| `auto` | 定義域の検査と backtracking 付きの Newton。進めない場合は Levenberg–Marquardt（LM）に切り替える |
| `newton`, `lm` | 同じ保護付きで、それぞれの方法だけを使う |
| `bracket` | B/C を明示したときのスカラー探索。J=0 は零電流の式、E_H 指定は準中性の式で N_e を消去し、一変数の符号変化を括弧付けする |

収束は元の方程式の残差が `residual_tolerance` 以下になることで判定します。小さな刻みや最小二乗の停留点は収束とみなしません。
初期値は、温度・密度に応じた無次元の標準初期値（`use_default_guesses`）、利用者が渡した `initial_guesses`、解マップの予測です。

**E_H 指定の B/C** の `auto` は、スカラー探索と、独立な多点出発の Newton/LM を併用します。スカラー探索の格子には、
bin 端とその直前・直後の浮動小数点値、対数・線形の電位点を含め、曲率に応じて区間を細分化します（`scalar_max_depth`）。
内部の極値から近接した根の組と接する根を探します。無効な評価点をまたいで区間を結ばず、区間幅が下限に達したことや
正の残差の極小は収束とみなしません。見つけた候補はすべて元の方程式と判定条件で検査します。

**候補の列挙** では、shifted deflation で既知の根を退けます。新しい候補も元の方程式と判定条件を満たす必要があり、重複は除きます。
初期値・反復・候補数はすべて有限で、全根の発見は保証しません。

**採用**: 収束した根は [物理解の判定](model.md#物理解の判定) を通ったものだけを返します。auto では判定を通らない根を飛ばして次の Type を試します。
採用候補がなく、棄却と未収束が混在した場合は数値探索の未解決（`SHEATH_NUMERICAL_FAILURE`）として返します。

## 解マップと continuation

解マップは、受理した根を無次元のキーで記録します。

| 表 | キー |
| --- | --- |
| J=0（6 次元） | log(T_e/V_s)、asinh(u)、log(u_i/v_s)、log(m_i/m_e)、log1p(α/V_s)、log1p(放出流束の規格化) |
| E_H 指定（7 次元） | 上の 6 次元に asinh(E_H/電場尺度) を加える |

（v_s は電位尺度に対応する電子の速さ、α = `ion_pressure_factor`·T_i。）
A/B/C、`component`、bin スペクトルの規格化した形はキーとは別に区別します。

問い合わせでは、近傍の記録から局所線形予測を作り（`interpolate`）、近傍の根とともに元の方程式の初期値にします。
それでも解けない場合は、近傍の記録から問い合わせ点まで continuation で追います。

- `parameter`: 入力の経路パラメータを 0→1 に進める predictor–corrector。刻みは適応的に変える。
- `arclength`: 擬似弧長の接線条件を加え、単純な折り返しを越える。

経路上で受理する点はすべて判定条件を通り、最後の点は問い合わせの条件そのもので解き直します。
解の移動が `max_root_distance` を超えた刻みは縮めて再試行します。
構築では後から見つかった近傍解を使って未解決の点を再探索しますが、空白の領域は不存在の証明ではありません。

## プロファイルの再構成

既存の根から、半無限の Poisson 一次積分で高さを積分します。探索は行いません。
A は極小を起点に境界側と上流側の二区間を作り、極小の $1/\sqrt{\phi-\phi_m}$ 型の端点は解析的に積分します。
B/C は上流の厳密な電位から積分し、無限遠の端点は除きます。
電位点は端点近くに集め、上流側は打ち切り電位で止めます。0 V の区間を人工的に付け足すことはしません。

## 浮動小数点の端点

非常に急な応答では、利用側の方程式を満たす電位が隣接する binary64 の値の間に入り得ます。
このとき、どの表現可能な電位でも残差の許容値を満たせません。
静的評価の `electron_normalization_m3` は、B/C の電位の直前・直後の値での中性密度の間に限って N_e を与え、
同じ N_e で密度・積分・流束をすべて評価し直します（[Fortran API](fortran-api.md#静的評価)）。
準中性と判定の許容値は緩めません。外側の方程式、その括弧付け、残差の規格化、時間積分は利用側の責務です。

## 検証

`fpm test`（`test/`）と `python -m unittest discover -s tests -v`（`tests/`）で、主に次を検査しています。

- 速度モーメントを独立な適応積分・Simpson 積分と比較。無ドリフト B の解析式と A→B の極限。
- 通過流束が複数の位置で一定であること、escape と return の和が外向き流束に等しいこと。
- 判定を満たさない代数根の棄却、負の表面電位を持つ A のプロファイル、非平坦な E_H=0 の遷移。
- プロファイルで E と −dφ/dz、dE/dz と電荷密度の整合。
- bin 源: 独立な局所速度積分・電位積分、Maxwell 源の細分化との一致、同じモーメントで形の異なる分布、bin 端の片側極限、
  狭い bin と隣接電位の精度。BEACH の batch-154 スペクトルを独立な高精度の静的参照値と比較。
- 上流の帯の受理、温かいイオン、解マップと continuation、結合 API（面上の条件とプロファイルの電位の極値・電場の一致、
  外部解の更新・失敗時の保持・stream/sequential での再開・版の不一致）。

上流の帯の物理的な解釈の検証は [upstream_relaxation_20261009](../outputs/upstream_relaxation_20261009/REPORT.md)、
matching plane で外向き流束を放出源とする定義の検証は [boundary_validation_20260923](../outputs/boundary_validation_20260923/REPORT.md) にあります。
