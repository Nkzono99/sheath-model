# 上流の低速電子を滑らかにしたときの零電流根（2026-10-09）

内向きに drift する電子と完全反射を仮定した A/C は、上流に接する狭い電位の帯で $E^2<0$ になる
（[kinetic-model.md](../../docs/kinetic-model.md#半無限プロファイルの存在条件)）。`upstream_band_tolerance` はこの帯を
許容して代数根を採用する。この検証は、帯の原因である低速電子の分布だけを物理的に滑らかにしたモデルで根を解き直し、
帯を許容した根が壁の量をどれだけ正しく与えるかを見積もる。

## 帯の物理的な意味

上流の電子分布 $f(v_z)$ は、入射側が drift した Maxwell 分布 $g(a)\propto e^{-(a-u)^2}$、反射側がその鏡像なので、
$f(v_z)=g(\lvert v_z\rvert)$ が $v_z=0$ で尖った極小を持つ（$f(v)-f(0)\approx g'(0)\lvert v\rvert$、$g'(0)=2ue^{-u^2}/\sqrt\pi>0$）。

- 密度: 極小の尖りが、上流近くの電子密度に $u\,h\log(1/h)$ の項を作り、$E^2<0$ を生む。
- 安定性: 電子の Penrose 条件の積分 $\int (f(v)-f(0))/v^2\,dv$ は、同じ尖りのため対数発散して正になる。
  鏡像で反射させた drift 分布は、drift の大きさによらず運動論的に不安定である。

不安定な尖りは、準線形緩和や表面の凹凸による散乱で平らにならされると考えられる。以下では、その緩和を最小限に
表すモデルとして、遅い入射電子だけ drift を除く。

## 方法

`smooth_slow_electrons.py` は sheath-model を使わない独立の解法である。冷たいイオンビーム、壁から放出される Maxwell
光電子、軌道整合の電子密度（$w^2=a^2+\psi$ の写像、反射は鏡像）、Poisson の第一積分を持つ。入射電子の分布を

$$
g(a)=\frac{e^{-a^2-u^2}}{\sqrt\pi}\left[\cosh(2ua)+w(a)\sinh(2ua)\right],\qquad w(a)=1-e^{-(a/a_s)^2}
$$

とする。$a_s=0$ は drift した Maxwell 分布、$a_s>0$ は速さ $a_s v_{th}$ より遅い電子の drift を除き、$g'(0)=0$ にする。
条件は BEACH の三層球と同じ: $n=5$ cm⁻³、$T_e=10$ eV、イオンと電子の drift 400 km/s（法線入射、$u=0.213$）、
光電子 4.5 µA/m²・2.2 eV。A は準中性・零電流・上側の接続（$E(0)=0$）、C は準中性・零電流を解き、
上流側の $E^2$ は上流端から積分して符号を調べる。

## 結果

$a_s=0$ では sheath-model の根を全桁で再現した（A: $\phi_0=6.03828$ V、$\phi_m=-0.78619$ V、$n_e=4.5852\times10^6$ m⁻³、
帯 52.05 mV、$E^2$ の最小 $-4.47\times10^{-7}$ V²/m²。C: $\phi_0=-7.34031$ V、帯 2.92 mV。drift 0 の A/C も一致）。

- 帯は $a_s$ がおおよそ $\sqrt{\text{帯}/T_e}$（A で 0.07、C で 0.017）を超えると消え、全域で $E^2\ge0$ になる。
  それより狭い滑らかさでは帯が残る（表の「—」は帯が残った根）。
- 帯が消えた根と、帯を受理した根の差は、$\phi_0$ と $\phi_m$ で数十 mV、電子の吸収束で 0.3% 未満。
  差は $a_s$ に依存し、$a_s=0.07$〜$0.2$ で A の $\phi_0$ は −23〜−81 mV、C（0.02〜0.2）は −1〜−81 mV 動く。
- drift を無視したときの差（A: $\phi_0$ 7.05 V、C: −4.63 V。帯を受理した根から約 1 V と 2.7 V）よりずっと小さい。

## 結論と限界

帯を許容した根は、遅い電子の分布を最小限に滑らかにした軌道整合の解と、壁の量で数十 mV 以内で一致する。
この差は、遅い電子の扱い（$a_s$）に由来する不定性と同程度である。BEACH はこの近似で電子の drift を扱う
（`sheath.zhao.upstream_band_tolerance = 0.1`）。

緩和の幅 $a_s$ は第一原理からは決まらず、不安定性の成長率や上流で緩和が進む範囲も評価していない。くぼみの幅
（$\lvert v_z\rvert\lesssim u\,v_{th}$）が自然な上限の目安である。
